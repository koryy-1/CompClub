# Система учета компьютерного клуба

## Компиляция и запуск:
1. Склонировать репозиторий

```sh
git clone https://github.com/koryy-1/CompClub.git
```

2. Перейти в директироию проекта

```sh
cd CompClub
```

3. Собрать проект

```sh
make
```

4. Запустить скомпилированный файл

```sh
./bin/main input_data/example.txt
```

## Очистка проекта

```sh
make clean
```

## Фичи
### Расчет выручки
Учет игровых сессий:
При обработке событий в методе ```TrackingSystem::Handle()``` жизненный цикл каждой сессии фиксируется в два этапа:
1. Начало сессии: когда клиент занимает стол, в объекте текущей сессии стола (```m_tables[i]->usageSession```) инициализируются идентификатор стола (```tableId```) и время посадки (```startTime```).
2. Завершение сессии: при уходе клиента или смене стола фиксируется время окончания (```endTime```), после чего сформированная запись сохраняется в общий журнал сессий ```m_tableUsageSessions``` для последующего расчета выручки.

После обработки всех событий в методе ```TrackingSystem::CalculateIncome()``` идет перебор ```m_tableUsageSessions```, вычисляется время использования ```usageTime``` и выручка ```income``` для каждого стола.

Это позволяет учитывать случаи, когда клиент, например, пересел с 1 стола на другой.

### Новые ошибки

- ClientHasAlreadyGone - клиент уже ушел, но происходит событие 2, 3 или 4
- WhyGetOnWaitingList? - клиент уже занял стол, но решил встать в очередь
